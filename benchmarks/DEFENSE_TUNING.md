# 铁桶与铁血猎犬调优

## 结果

2026-11-22，本机 Java 26.0.2。两队的英雄组成、每步默认 0.25 秒预算及战斗规则保持原值。其他八队配置和通用搜索策略保持原值。以下 Elo 均为对照赛从 1500 起、K=24 按相同赛程计算，便于比较；不同赛程的 Elo 不直接比较。

### 默认 0.25 秒预算，动态搜索深度

未参与调参的 base seed=90000，每个对手 4 局，每队共 32 局，正反座位各半。

## 原因与改动

通用搜索的叶子估值主要关注存活、当前 HP、压力阈值、守护/反击标志，对护甲、闪避、减伤 debuff 和永久全队增益的后续价值缺少估计。动作排序也使永久增益难以战胜眼前输出。搜索视野短时，这会让防守队错过建立优势的窗口。

新增 `FortressBot`，保留通用搜索框架，通过两个受保护扩展点定制动作价值和置换表键：

- 将有效防御、闪避、压力抗性和敌方减伤计入中期价值，让架势建立与持续压制在浅层搜索中可见。
- 加强压力积累的价值，鼓励防守后的持续输出，减少低威胁下无意义的守护。
- 对永久增益增加启动价值，限制重复再生的溢出价值；危急救援单独检查优先级。
- 使用更集中的搜索候选宽度。置换表键包含 buff 实际内容和持续时间、DoT、技能次数、冷却、守护对象，避免仅凭 buff 数量把不同防守状态混同。

技能和饰品的最终改动：

| 英雄 | 铁桶 | 铁血猎犬 |
| --- | --- | --- |
| 苦修 | 惩戒、悲痛之雨、救赎之血、救赎；保留赦免护手/猩红弯钩 | 同铁桶 |
| 十字军 | 狂热指控、光明壁垒、迎向火焰、震慑重击；荣耀之旗/神圣之刃 | 狂热指控、光明壁垒、迎向火焰、圣枪冲锋；荣耀之旗/执行令 |
| 老兵 | 震天咆哮、铁壁守护、鼓舞士气、惩戒反击；斗士头盔/怪异之眼 | 相同技能；斗士头盔/麻木熏香 |
| 第四人 | 盗墓：恐慌飞镖、飞刀连掷、暗影消逝、毒素戏法；保留暗器背包/猴爪 | 训犬：猎犬骚扰、猎犬突袭、护卫猎犬、舔舐伤口；保留攻击哨/猴爪 |

以 JSON 中的英文技能 ID 为准。苦修补上不受低血量限制的前排攻击；盗墓减少突刺引起的队友错位，使用匕首降低流血抗性并配合苦修；猎犬补上单体输出，十字军带圣枪应对错位。保留群体护甲、提振、守护和多点治疗的防守框架。

## 拆分验证

相同的 512 局固定深度验证中：

| 改动 | 铁桶胜场 | 猎犬胜场 |
| --- | ---: | ---: |
| 原版逻辑 + 原版配置 | 291 | 336 |
| 原版逻辑 + 新配置 | 317 | 325 |
| 新逻辑 + 原版配置 | 395 | 433 |
| 新逻辑 + 新配置 | 419 | 445 |

只改技能和饰品对猎犬甚至有负面作用；长期价值评估和配装需要配合。这组结果支持优先修正防守队的决策逻辑。

## 复现

项目根目录执行：

```powershell
.\build.ps1
java -Xmx512m -cp 'java/out;java/out-test' com.circus.FortressBotTest
java -Xmx512m -cp 'java/out;java/out-test' com.circus.TournamentPerformanceTest

# 原版与当前版，同一组固定深度赛程，各 1,024 局。
java -Xms512m -Xmx1g -cp 'java/out;java/out-test' com.circus.DefenseEvaluation baseline 64 0.46 20000 4 2
java -Xms512m -Xmx1g -cp 'java/out;java/out-test' com.circus.DefenseEvaluation final 64 0.46 20000 4 2

# 默认预算，最后一个参数 0 表示沿用各 bot 的动态搜索深度上限。
java -Xms1g -Xmx2g -cp 'java/out;java/out-test' com.circus.DefenseEvaluation baseline 4 0.25 90000 8 0
java -Xms1g -Xmx2g -cp 'java/out;java/out-test' com.circus.DefenseEvaluation final 4 0.25 90000 8 0
```

旧队伍配置保存在 `java/test/resources/defense-baseline/`。原版策略使用行为未改动的 `CircusSearchBot`；验证它与本次工作开始时冻结的策略在全部 1,024 局固定深度赛程上结果完全一致。对手来自其他八个 `team/*.json`，复现时应保持其配置不变。报告保存完整配置、参数、逐局胜负和 Elo。

原始结果：`defense-baseline-20000-0.46-d2.json`、`defense-final-20000-0.46-d2.json`、`defense-baseline-90000-0.25-d0.json`、`defense-final-90000-0.25-d0.json`。拆分验证为 `defense-loadout-only-20000-0.46-d2.json`、`defense-logic-only-20000-0.46-d2.json`。调参使用 1000/2000/3000 等种子，以上验证种子未用于选择配置。

新增回归检查通过：配装合法、永久防御/敌方减伤可见、置换表区分不同 buff、搜索不修改实盘、救援优先于启动。既有性能回归也通过。完整套件仍为 15 项通过、1 项既有 FMOD 音频导出失败，记录于 `defense-suite.txt`。
